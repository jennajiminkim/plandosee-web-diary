## 2026-10-25 후속 검증: 자유로운 할 일, 집계 및 내보내기

- **'연결된 계획 없음 — 자유로운 할 일'은 의도된 기능.** 사용자 설명을 확인하고 실제 DB의 `plan_id IS NULL` 활성 할 일 5건을 확인. 삭제/누락된 계획을 참조하는 활성 할 일 0건. 오류 아님.
- **C28–C32 집계 DB 재계산:** 프런트엔드 `renderSummary()`의 `planTasks(selectedPlan)` 기준으로 활성 계획별 할 일과 연결된 실행 기록을 SQL에서 합산함. 계획 A: 계획 1, 완료 0, 지연 0, 막힘 0, 예상 30분, 실제 0분, 차이 -30분. 계획 B: 계획 5, 완료 3, 지연 2, 막힘 1, 예상 1590분, 실제 1741분, 차이 +151분. 운영 화면 수치와의 직접 비교는 미실시. 오늘 날짜는 SQL에서 `Asia/Seoul` 적용.
- **C36 코드 검사:** `exportAll()`은 `load()`로 받은 `state` 전체와 앱 이름·내보낸 시각·시간대 규칙을 JSON으로 직렬화하고, Blob으로 `plan-do-see-YYYY-MM-DD.json` 단일 파일 다운로드를 트리거함. 상단·본문 내보내기 버튼 모두 연결됨. **실제 파일 다운로드 및 원본 DB 레코드 수/ID와의 비교는 아직 미실시**.
- **C83 코드 검사:** 통계 버튼은 `showEvidence()`에서 해당 그룹의 할 일 버튼을 표시하고, 선택 시 `openTask(t)`로 이동. 시간 상세는 `timeDetails`에서 할 일별 예상/실제 합계와 상세 이동 버튼을 표시함. 실제 클릭 검증은 미실시.
